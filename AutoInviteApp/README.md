# VRChat Auto Invite — TGC Fork

This is Seawolf's maintained fork of **Titan_BCXR's VRChat Auto Invite launcher**.

## Credits

- **Original launcher:** Titan_BCXR
- **Later updates:** MILK & Ajaken365 for Site-19 usage
- **Further development:** Seawolf for The Gamer Club

Original upstream: https://github.com/TitanBCXR/vrchat-auto-invite

## Current TGC functionality

The current build retains the original inviter while adding file-based `usr_...` invites, current-instance inviting, separate logging, encrypted persistent VRChat sessions/2FA handling, and the Pending Invite Recycler.

The Pending Invite Recycler is also available separately as a plugin download from the latest GitHub Release.

See `PENDING_INVITE_RECYCLER_README.txt` and `VRCX_STYLE_SESSION_README.txt` for details.

## Windows

Run `AutoInvite.bat`, or install `requirements.txt` and run `python main.py`.

Python 3.8+ is required.
