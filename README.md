# vrchat-auto-invite

This repository is a maintained fork of [TitanBCXR/vrchat-auto-invite](https://github.com/TitanBCXR/vrchat-auto-invite).

The original launcher was created by **Titan_BCXR**. Later updates were made by **MILK & Ajaken365** for Site-19 usage, with additional development by **Seawolf** for **The Gamer Club**.

This fork contains the current TGC Auto Invite launcher, including file-based VRChat user-ID invites, persistent login/session improvements, and the Pending Invite Recycler.

## Running

Open the `AutoInviteApp` folder and run `AutoInvite.bat`, or install the Python requirements and run `python main.py`.

## Plugin Downloads

The **Pending Invite Recycler** is also available as a standalone plugin download from the latest GitHub Release.
